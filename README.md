# Todo App - Modern Task Manager

A beautiful, minimalist Todo application built with React, Node.js, and SQLite.

🚀 **Live Demo:** [https://todo-zeta-ebon.vercel.app/](https://todo-zeta-ebon.vercel.app/)

## Features

- **Minimalist Design**: Clean interface with a premium dark gradient background.
- **Full CRUD**: Add, Edit, Delete, and Complete tasks.
- **Responsive**: Works perfectly on desktop and mobile.
- **Persistent Data**: Uses SQLite backend for reliable data storage.
- **One-Click Run**: Simple command to start both frontend and backend.

## Tech Stack

- **Frontend**: React (Vite), TailwindCSS
- **Backend**: Node.js, Express
- **Database**: SQLite (Sequelize ORM)

## Run Locally

Clone the project and run it with a single command:

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/OmeGa8989/Todo.git
    cd Todo
    ```

2.  **Install Dependencies**:
    ```bash
    npm install
    cd frontend && npm install
    cd ../backend && npm install
    cd ..
    ```

3.  **Start the App**:
    ```bash
    npm run dev
    ```
    This will launch:
    *   Backend API at `http://localhost:5000`
    *   Frontend App at `http://localhost:5173`
